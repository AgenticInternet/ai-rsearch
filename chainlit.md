# Welcome to DeepAgents Search System 🚀

## What is this?

This is an **AI-powered multi-agent search orchestration system** that combines:

- 🔍 **SerpApi** - Live web search (Google, News, Trends, Images)
- 🗄️ **Algolia** - Semantic indexing and intelligent search
- 📊 **OpenSearch** - Analytics and performance tracking
- 🧠 **DeepAgents** - Intelligent multi-agent coordination
- ⚡ **Claude Sonnet 4** - Advanced language model

## How it works

When you submit a query:

1. **Planning** - The orchestrator breaks down your query into subtasks
2. **Research** - Web researcher agent searches across multiple sources
3. **Indexing** - Object indexer stores and organizes findings
4. **Analytics** - Performance tracker monitors all operations
5. **Synthesis** - Results are combined into actionable intelligence
6. **Documentation** - All findings are saved for reference
